# Character Naming Diversity Bank — Global Storytelling
## Anti-Duplication Engine & Cultural Matrix System

> [!IMPORTANT]
> **ANTI-DUPLICATION LAW & REGISTRY CHECK (MANDATORY)**:
> 1. Before generating any character profile, inspect `history-registry.json` (`used_character_names`).
> 2. **ZERO FIRST-NAME REUSE**: If a first name (e.g. `Clara`, `Victor`, `Tobias`, `Arthur`, `Miriam`, `Corvin`, `Gideon`) appears in `used_character_names`, it is **STRICTLY BANNED** across all future stories.
> 3. **ZERO SURNAME REUSE**: If a surname (e.g. `Vance`, `Sterling`, `Drake`, `Thorne`, `Boone`) appears in `used_character_names`, it is **STRICTLY BANNED**.
> 4. **SETTING-NAME HARMONY**: Character names MUST match the story's setting, era, and cultural atmosphere (no 19th-century Victorian names in Ancient Karma or Mediterranean stories).
