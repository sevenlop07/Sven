# assets/anims — Mixamo FBX clips (NOT for Roblox films)

These `.fbx` clips exist only for `studio_kit/blender_r15_hybrid.retarget_mocap_to_r15` on **non-Roblox projects** or an
explicit user request. **Law R-ANIM** (`.agents/ROBLOX_DIRECTOR.md` §4.1 rule 1) bans mocap retargeting onto the blocky
Roblox R15 rig in final films: human twist, lean and cadence break the Roblox look.

For Roblox acting use `studio_kit/blender_roblox_anim.py` (`RobloxAnimator`, 27 code-rigged states) in Blender, or the
official R15 animation ids (§4.6) in Roblox Studio.
